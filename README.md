# Calendrier cyclocross élite 2026-27

Un calendrier `.ics` avec les courses élite Hommes et Femmes de la saison de cyclocross 2026-27, à ajouter dans ton agenda.

**URL d'abonnement :**

```
https://eliobou.github.io/cx-calendar/cyclocross-elite.ics
```

Fichier : [`docs/cyclocross-elite.ics`](docs/cyclocross-elite.ics)

## Contenu

40 courses, soit 80 événements (un pour les Femmes, un pour les Hommes) :

- **Coupe du Monde** UCI (12 manches)
- **Superprestige**
- **X²O Trofee**
- **HG Cross**
- **Championnats** : Europe, Belgique, Pays-Bas, France, Monde

Chaque événement contient :

- le nom de la course et la catégorie (ex. *Coupe du Monde Namur – Hommes*) ;
- le lieu ;
- l'heure de départ, que ton agenda affiche dans ton fuseau horaire. La note précise l'heure de Paris.

⚠️ La plupart des heures sont **estimées** à partir des horaires habituels et marquées « heure estimée, à confirmer » dans la note. Chaque événement dure 1 h, de façon arbitraire. Le lieu du championnat de France n'est pas encore connu.

## Ajouter le calendrier

Mieux vaut **s'abonner à l'URL** plutôt qu'importer le fichier : les corrections (heures confirmées, lieux) arrivent alors automatiquement dans l'agenda.

### Apple Calendrier (Mac)

1. Fichier → **Nouvel abonnement à un calendrier…**
2. Colle l'URL, puis S'abonner.
3. Emplacement : **iCloud** (pour l'avoir aussi sur iPhone). Actualisation automatique : **Chaque jour**.

### iPhone / iPad

Réglages → Apps → Calendrier → Comptes → **Ajouter un compte** → Autre → **Ajouter un calendrier avec abonnement**, puis colle l'URL.
(Inutile si l'abonnement a déjà été créé sur le Mac dans iCloud.)

### Google Agenda

1. Sur ordinateur, sur [calendar.google.com](https://calendar.google.com) : à gauche, **+** à côté de « Autres agendas » → **À partir de l'URL**.
2. Colle l'URL, puis Ajouter l'agenda.

Le calendrier apparaît ensuite sur l'app Android et iOS. Google ne recharge les abonnements que toutes les 12 à 24 h environ.

### Outlook

- **Outlook.com / Outlook web** : Calendrier → **Ajouter un calendrier** → **S'abonner à partir du web**, puis colle l'URL.
- **Outlook pour Windows (classique)** : Accueil → Ajouter un calendrier → **À partir d'Internet…**

### Autres applis

Toute appli qui accepte un abonnement iCal / `.ics` / `webcal://` fonctionne (Thunderbird, Proton Calendar, Fantastical…). Pour une copie figée, sans mises à jour, tu peux aussi télécharger le fichier et l'importer.
